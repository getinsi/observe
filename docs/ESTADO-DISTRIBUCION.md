de GetInSI Observe. Una versión publicada puede permanecer disponible mientras
el desarrollo continúa por separado; no tiene que coincidir con el código más
reciente del proyecto.

## Cómo interpretar la documentación

El README y las notas de cada publicación describen el producto distribuido.
Los cambios del desarrollo posterior requieren una nueva entrega antes de
considerarse disponibles en el paquete de este canal. La documentación de una
aplicación más reciente no acredita las funciones de un instalador anterior.

Esta actualización solo documenta el canal. No reemplaza el ZIP, modifica una
publicación ni incorpora fuentes de desarrollo. El trabajo de un nuevo
instalador está aplazado por decisión del propietario.

## Para una publicación futura

Cuando se retome una entrega, sus notas deberán identificar versión y archivo,
procedencia de la construcción, cambios incluidos, alcance de las comprobaciones
y checksum del paquete. El usuario deberá poder distinguir esa entrega de las
anteriores sin deducir equivalencias a partir del nombre de un archivo.

No se anuncia una fecha ni una nueva versión con este documento. El enlace de
descarga vigente sigue siendo [GitHub Releases](https://github.com/getinsi/observe/releases).
